# MoonCurveFit

`yyyt0807/curvefit` is a pure MoonBit small-dense nonlinear least-squares library. It targets instrument calibration, scientific kinetics and offline browser analysis. The same numerical code runs on native, JavaScript and wasm-gc.

Development in progress. There is no published release or passing remote CI yet. Local work is retained in meaningful Git commits. See `docs/adr/` for scope and `docs/third-party.md` for provenance.
